バックアップ

演習結果は、お使いのブラウザに自動保存されています。別のPCで使う・万一に備えるため、定期的にJSONとして書き出してください。

差分マージ復元とは: 現在のデータを保ったまま、選択した JSON ファイルにある「不足分」(解答履歴・フレーム履歴・ブックマーク・問題・図表など)を追加します。
例: 事務所PCで作り忘れたバックアップを後から自宅PCのデータに統合したい場合に使用します。同一IDのデータで内容が違う場合は「新しい方」を採用します(初期判定は最終解答日時で自動判定、UIで切替可)。

ストレージ診断

「保存に失敗しました」などのエラーが出るとき、または容量が気になるときに使ってください。
iPhone Safari の localStorage は約 5MB 制限です(図表画像・問題・履歴・条文などの大容量データは IndexedDB に分離保存されるためこの制限の対象外)。

問題データの追加方法

大量の問題を追加するときは、JSONで一括投入できます。「問題管理」→「JSONインポート」から下記の形式で貼り付けてください。

[
  {
    "year":"R3","law":"雇用保険法","qno":"問2 肢B",
    "category":"未支給の失業等給付",
    "text":"問題文…",
    "answer":false,
    "point":"ポイント…",
    "explanation":"解説…",
    "legalBasis":"法10条の3、1項",
    "articleText":"(条文本文 任意)",
    "difficulty":"C"
  }
]

※ answer は ○=true、×=false。書籍ページを撮影してClaudeに渡せば、この形式のJSONに変換できます。

注意事項

データはブラウザの localStorage と IndexedDB (図表画像・問題・履歴・条文など) に保存されます。ブラウザのキャッシュ削除でデータが消える可能性があるため、定期的なバックアップを推奨します。
